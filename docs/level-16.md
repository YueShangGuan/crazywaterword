# 16 级玩法指南

刚升到 16 级，最先值得做的是挑战强化石副本，以及找世界海盗拿第一块农田需要的有机土壤。以下门槛取自 74 版游戏配置；建筑、舰队和首杀进度以当前账号为准。

| 想做什么 | 从哪里开始 | 条件和收益 |
| --- | --- | --- |
| 拿第一笔强化石 | 控制台 **挑战 → 试炼副本 → 挑战强化石副本** | 每次点击挑战下一关。第一关配置战力为 12.5 万，首通奖励含 2,800 强化石。通关后可在 **挂机 → 挑战** 开启「试炼副本免费扫荡」；当前配置每个副本每天有一次免费扫荡。 |
| 给农田备土 | 控制台 **活动 → 海盗首杀** 查看地图上可见的目标，再到游戏世界地图打首杀 | 第一块农田要 100 有机土壤。看对应海盗的首杀奖励，已领过的一档不能重复刷；游戏还列有联盟商店来源。「讨伐野怪」按日常任务扫荡，不会替你挑首杀目标。 |
| 生产种子 | 控制台 **单次操作 → 海面** 查看建筑和工厂队列 | 16 级可建选种厂，需要 2,400 金币、10 建筑蓝图和 6 粗铁。1 级金属厂可产粗铁：每个用 40 废金属、4 淡水。选种厂 1 级产小麦种子，升到 2、3、4 级依次开放玉米、土豆、番茄种子。农田和选种厂各有自己的建造条件。 |
| 减少种田时间 | 控制台 **英雄 → 英雄任命 → 查看职位** | 16 级新增「种田时间」职位。点「一键任命」会按游戏内优先顺序重新分配可用英雄，其他职位也可能调整。 |
| 查看世界资源田 | 控制台 **单次操作 → 资源田** | 16 级开放世界、舰队码头和远征舰队建筑。报告可以查看占地和舰队状态。建筑竣工和拥有一支可出征的舰队是两个条件。 |

**哪些要回游戏操作？** 16 级也达到联盟和英雄装备的开放门槛，控制台还没有联盟日常或英雄装备穿戴、强化入口。「英雄主题副本」和「海上风采大赛」也有 16 级门槛，能否参加要看当期活动是否开放。回游戏前可先暂停托管，避免顶号。

**17 级有什么变化？** 游戏配置在 17 级开放周活动和海商王。控制台支持周战令领奖、周抽奖免费礼包和累计次数奖励；周订单按缺口备料，由玩家手动交单。海商王是另一项活动，和控制台已有的贸易港交货、收货是两种玩法。
