# 疯狂水世界 · 航行控制台

![Node.js 20.11+](https://img.shields.io/badge/Node.js-20.11%2B-417E38) ![Windows](https://img.shields.io/badge/Windows-本地控制台-0078D4) [![ISC License](https://img.shields.io/badge/license-ISC-blue)](LICENSE)

在本机管理《疯狂水世界》账号，用独立开关安排领奖、工厂排产和船只采集。控制台直接连接游戏 WebSocket，运行日志会告诉你这一轮收到了什么，以及哪些操作因材料、等级或建筑数量不足而跳过。

[快速开始](#快速开始) · [功能一览](#功能一览) · [16 级玩法指南](docs/level-16.md) · [更新日志](CHANGELOG.md) · [玩法与协议](docs/gameplay.md)

## 快速开始

需要 Windows 和 Node.js 20.11 或更高版本。默认安装流程从电脑版微信的游戏缓存读取协议和配置，请先在微信里打开一次《疯狂水世界》。如果要添加抖音账号，还要在同一台电脑上登录电脑版抖音。

```powershell
git clone https://github.com/xutongxue233/crazywaterworld.git
cd crazywaterworld
npm ci
npm run sync-config
.\start-console.cmd
```

1. 打开 [本地控制台](http://127.0.0.1:17323/)，进入 **账号**，根据游戏客户端选择 **从电脑微信添加** 或 **从电脑抖音添加**。等控制台提示正在采集，再从对应客户端重新进入《疯狂水世界》，查看日志中的角色验证结果。
2. 进入 **挂机**，为这个账号选择自动任务。首次测试可把轮数设为 `1`，在运行日志核对收益；设为 `0` 表示持续运行。
3. 想自己上号时，在控制台点 **暂停托管**。这会断开工具的游戏连接，避免两个会话互相顶号。挂机期间可关闭浏览器，启动窗口需要保持打开。

> 请只用自己的账号测试。自动化操作会改变游戏内的资源和进度，使用第三方工具有账号处罚风险。采集凭证会临时更改当前 Windows 用户的代理和证书设置。账号凭证与导出文件含登录信息，请留在本机。

**居民订单**在「单次操作 → 海面」。即使关闭「自动交居民订单」，也可以点某位居民的「提交订单」。提交前控制台会重新核对订单和库存。周订单还缺材料时，可先满足已经备齐的居民单，排产会补回用量；周订单整单齐备时，所需库存留给玩家在游戏中手动提交。控制台不自动交周订单。

「挂机 → 海面 → 为待建建筑补产材料」默认关闭。开启它以及「空位建造」「工厂排产」后，若一个待建建筑缺的材料都能由现有工厂生产，控制台会优先安排订单，再补建材。例如金属厂建成后，可按选种厂缺口排产粗铁。排队中和已完工待收的产品都计入备料。

装备厂收取和自动制造是两个独立开关；希望连续生产时应同时开启。联盟订单只使用扣除其他订单预留后的现有材料，本阶段还不会为联盟订单额外排产。联盟情报每艘空闲舰队只分配一个可确认的目标，维修按服务器给出的成本计算；没有足够战力、耐久或汽油时跳过，详情见运行日志。需要捐物资的难民情报、城战试探和占领宝藏暂时跳过。情报、维修与手动海盗出征共享舰队预占；其他玩法的出征结果或汽油扣除尚待确认时，先等待再执行新的耗油操作。

博物馆探险到期后需要先结算、再领取奖励与探索进度，领取确认后才能释放该队英雄并继续派遣。这两步统一由「到期结算并领取探险奖励」处理；「派遣博物馆探险队」独立控制新探险。海兽只有确认成熟产物入库后才继续培育，投喂和付费加速暂未接入。两类玩法都会按服务端结束时间安排复查，缺少材料、合适英雄或空位时在日志说明原因。

装备制造与海兽培育会共同核对未同步的金币扣款，联盟订单与博物馆会共同核对材料扣款。队列或奖励已确认、余额仍未更新时，后续消耗会等待库存同步，避免误用同一份余额；同一进程内重新连接仍保留这项检查。

**运行日志**用中文显示每轮结果，可筛选「警告与错误」。同一工厂连续安排相同产品时会合并显示，展开可看逐次排产或错误详情。挂机页显示已排定的下次检查时间，手动点击「一键领取」则立即重新查询。

## 常用命令

| 命令 | 用途 |
| --- | --- |
| `npm start` | 直接启动控制台，默认端口为 `17321`；Windows 启动脚本默认用 `17323` |
| `node src/app.mjs world --dry` | 查看一轮海面经营计划 |
| `node src/app.mjs stages --max-failures 3 --yes` | 开始主线推关，同一关连续失败 3 次后停止 |
| `npm run sync-art` | 将微信缓存中的游戏素材同步到本地，供控制台重复使用。缓存缺图时可用 `npm run sync-art -- --fetch` 从游戏 CDN 补齐 |
| `npm run build:ui` | 修改界面组件后重新生成控制台页面和样式 |
| `npm test` | 运行协议、玩法和挂机自检，需要本机可读取的游戏协议包 |
| `npm run test:level16` | 单独验证试炼扫荡、英雄装备、联盟福利、首次编队和海盗首杀 |
| `npm run test:progression` | 离线验证装备厂、联盟情报与维修、联盟订单、博物馆、海兽培育和挂机开关接入 |

<summary>协议、配置或图标缺失时</summary>

- **协议包**：先在电脑版微信打开游戏。自定义缓存路径可在 PowerShell 设置 `$env:CW_PROTO_BUNDLE = 'D:\游戏缓存\_src_chunks_.wxapkg'`，再启动控制台。
- **配置与素材**：配置包和图集保存在 `work/`，不会随仓库分发。游戏已下载资源后，可分别运行 `npm run sync-config` 和 `npm run sync-art`。
- **账号与日志**：账号和工厂报告默认保存在 `data/`，可通过 `CW_DATA_DIR` 改目录。运行日志保留在当前控制台会话，原始协议日志写入项目的 `data/protocol.log`。控制台端口由 `CW_PORT` 指定。

## 扩展自动化与控制台

本分支在上游功能基础上增加按账号保存的自动化设置、计划预览、单轮及循环执行。新增模块默认关闭；先选择赛季、英雄与消费限额，再预览计划。启用新版模块后，重叠玩法由新版模块统一执行，上游独有功能继续保留。每次修改设置后请先运行一轮核对结果。

- 自动化模块覆盖基地、农田、居民订单、货船、选择事件、采集、挂机、英雄、藏品、宠物、装备、博物馆、挑战、世界、联盟、福利和活动等玩法；独立商店模块不在范围内。
- 总览增加舰队状态、作物容量与分类消息；日志支持选择保护和复制。
- `/mobile` 是使用虚构数据的独立交互原型，不连接游戏，不代表真实账号状态。
- 异常断线可通知并恢复挂机；账号在其他位置登录时不自动抢登。主动断开后，轮询不会自动登录。
- 企微通知地址、账号凭证、自动化设置及执行账本仅保存在本地，切勿上传 `data/`、`work/`、浏览器记录或账号导出文件。
- 操作可能消耗游戏资源并带来账号处罚风险，只能使用自己的账号测试；钻石消费等敏感选项必须显式开启。

```powershell
node src/app.mjs automation settings
node src/app.mjs automation plan farm
node src/app.mjs automation run all --yes
npm run test:offline
```

模块计划会读取游戏状态并使用所选账号连接网关；设置和本地运行状态查询不连接游戏。协议审计见 [自动化覆盖](docs/automation-coverage.md) 和 [请求依据](docs/automation-requests.md)。
